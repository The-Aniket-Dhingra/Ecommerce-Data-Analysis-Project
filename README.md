# 📈 Ecommerce Data Analysis Project

A data analysis project that uncovers insights from **messy ecommerce data** using Python, MySQL and data visualization techniques (Power BI and Tableau).

---

## 🚀 Overview

This project analyzes **messy ecommerce data** to answer key business or research questions through data cleaning, exploration and visualization.

### Goals

- Understand the dataset
- Clean and preprocess the data
- Perform exploratory data analysis (EDA)
- Visualize important trends
- Draw actionable insights

---

## 📊 Data Source
The dataset used in this project is **entirely synthetic and AI generated**. This dataset is generated from **Google Gemini**. No real-world and personal data is used.

### Dataset Information
- Number of Rows - 10,150 
- Number of Columns - 14
- Format - CSV

--- 

## 🛠 Tech Stack

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- MySQL
- Power BI
- Tableau

---

## 💡 Key Insights

- The month in which the revenue is highest is January.
- The month in which the revenue is lowest is December.
- The month in which the revenue loss in highest is May.
- The month in which the revenue loss is lowest is October.
- Highest revenue generating weekday from all over the year is Sunday.
- The category which generates the highest revenue is Electronics.
- The sub category which generates the highest revenue is Laptops.
- The category which generates the lowest revenue is Clothing.
- The sub category which generates the lowest revenue is Skincare.
- The customer who spends the highest is Megan Thomas.
- Highest revenue generating payment method is Apple Pay.
- The category whose sales is highest is Electronics.
- The sub category whose sales is highest is Smartphones.
- The category whose sales is lowest is Home & Kitchen.
- The sub category whose sales is lowest is Cookware.
- There is not much relation between discount and quantity sold because we can see that the quantity sold with no discount is much more than the quantity sold with discount.
